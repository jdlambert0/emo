## 🚀 Quick Start

### 1. Download Files
Download all files:
- `index.html`
- `styles.css`
- `mhh-engine.js`
- `app.js`

### 2. Get an API Key

#### Option A: OpenAI (GPT-4)
1. Go to [platform.openai.com](https://platform.openai.com/)
2. Create an account
3. Navigate to API Keys
4. Create a new secret key
5. Copy the key (starts with `sk-`)

#### Option B: Anthropic (Claude)
1. Go to [console.anthropic.com](https://console.anthropic.com/)
2. Create an account
3. Navigate to API Keys
4. Create a new key
5. Copy the key (starts with `sk-ant-`)

### 3. Open the App
1. Simply **double-click `index.html`** to open in your browser
2. Click the **⚙️ Settings** button
3. Select your AI provider (OpenAI or Anthropic)
4. Paste your API key
5. Close settings

### 4. Start Chatting!
- Choose a mode: **Learn** or **Chat**
- Type a message
- The AI will respond with emotional intelligence

**That's it!** No installation, no server, no complicated setup.

## 📖 How It Works

### The Webb Equation
All emotions follow a mathematical formula:

```
EP ∆ P = ER
```

- **EP** (Expectation/Preference): What you want
- **P** (Perception): What actually happened
- **ER** (Emotional Reaction): The resulting emotion

The app analyzes your messages, identifies affected attachments ({self} map items), and calculates emotions using this framework.

### Learn Mode
Progressive education through:
1. **Novice**: Basic emotional vocabulary and concept discovery
2. **Intermediate**: {self} map building and pattern recognition
3. **Advanced**: Theory of Mind and strategic communication
4. **Mastery**: Peer-level emotional intelligence discussions

### Chat Mode
Open conversations where the AI:
- Understands your emotions mathematically
- Responds with deep empathy
- Applies Webb Equation insights naturally
- Discusses any topic with emotional intelligence

## 🔐 Privacy & Security

### What Data is Stored Locally?
- Conversation history
- API key (encrypted in browser storage)
- Skill progress (Learn Mode only)
- Settings preferences

### What Data Leaves Your Device?
**Only your messages to the AI provider** (OpenAI or Anthropic) to generate responses. Your API key is sent directly to them via secure HTTPS.

**Never sent:**
- Your emotional analysis
- Your conversation history
- Your skill progress
- Any identifying information

### How to Delete Your Data?
Click **Settings ⚙️ → "Clear All Local Data"** button.

## 🎨 Customization

### Change Voice (Text-to-Speech)
Settings ⚙️ → Voice → Select your preferred voice

### Disable Features
Settings ⚙️ → Uncheck:
- "Enable Text-to-Speech" - Turn off audio
- "Show Emotional Analysis" - Hide Webb Equation details

### Switch AI Providers
Settings ⚙️ → AI Provider → Select OpenAI or Anthropic

You can switch anytime! Your conversation history is preserved.

## 🛠️ Troubleshooting

### "Error: API key is invalid"
- Double-check you copied the full key
- Make sure there are no extra spaces
- Verify the key matches the selected provider

### Messages aren't sending
- Check your internet connection (required for AI responses)
- Verify your API key is set correctly
- Check the browser console (F12) for error messages

### Text-to-speech not working
- Ensure "Enable Text-to-Speech" is checked in Settings
- Try a different voice
- Check browser permissions for audio
- Some browsers block TTS on file:// URLs - try opening via a local server

### Starting fresh
Settings ⚙️ → "Clear All Local Data" → Restart browser
